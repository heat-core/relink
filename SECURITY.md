# Security

Report suspected vulnerabilities in private through [GitHub vulnerability reporting](https://github.com/heat-core/relink/security/advisories/new) once enabled. Include the version, affected component and a minimal description with synthetic data. Keep credentials, device logs, personal data and technical details of a suspected vulnerability out of public issues. If private reporting is unavailable, wait for a private contact before sharing those details.

ReLink uses authenticated link sessions for paired devices over Bluetooth or local Wi-Fi. Local Wi-Fi is intended for trusted networks. Android call audio requires separate OS-level debugging authorization and is experimental. Use the Android package installer with Play Protect enabled. Release signing keys are held offline by the owner. Source publication and signed binary releases have separate review gates.
